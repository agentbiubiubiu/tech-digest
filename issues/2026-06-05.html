📰 科技动态

1、VoidZero 加入 Cloudflare：Vite 生态获千万美元基金加持 confirmed

Evan You 的 VoidZero 团队被 Cloudflare 收购——但不是「收购」，Vite、Vitest、Rolldown、Oxc 全部保持 MIT 开源与厂商中立。Cloudflare 同时承诺 100 万美元 Vite 生态基金。Vite 周下载量 1.29 亿次，Evan You 指出 AI Agent 正成为 dev server 的新用户。前端基础设施格局正式进入「大厂托管开源关键链路」时代。

2、Elixir v1.20：无需注解即可全程序类型推断 confirmed

Elixir 完成首个类型系统里程碑——无需写任何类型注解，编译器自动对全部程序做渐进类型检查，高效发现死代码与运行时必败的类型冲突。团队用独特的 dynamic() 类型实现兼容性，误报率极低。这是动态语言「后天补课」的教科书案例。

3、GitHub.dev 漏洞：一键窃取 OAuth Token reported

安全研究者披露 GitHub.dev 存在严重缺陷，攻击者通过单次点击诱导用户泄露 OAuth 令牌。浏览器端开发环境的供应链安全风险再次凸显——你以为在写代码，攻击者已经拿到你的身份。

4、Apple 批准首个 AI Agent 进入 Messages for Business confirmed

Poke 成为首个获准在 Apple Messages for Business 运行的独立 AI Agent，用户可通过 iMessage 完成日程、健康、智能家居等操作。Apple 按用户收费，Poke 估值达 3 亿美元。WWDC 前释放的信号：Apple 的 Agent 策略是做平台，不是做模型。

5、Meta 智能眼镜内置完整人脸识别管线 confirmed

安全研究员在 Meta 智能眼镜伴侣应用 Stella v273 中发现三套端侧人脸模型、2048 维向量索引与「Person recognized」通知通道，并在测试中跑通端到端识别。用户界面尚未启用，但完整识别与未匹配人脸暂存机制已部署在设备上。

🤖 AI 相关

1、Anthropic 公布递归自我改进数据：80% 合并代码由 Claude 编写 confirmed

Anthropic Institute 发布长文，披露 AI 加速 AI 开发的量化数据：工程师季度代码产出约为 2021-2025 年均值的 8 倍，超过 80% 合并代码由 Claude 编写。任务可靠完成时长约每四个月翻倍。文章同时讨论完全自主设计下一代模型的治理挑战——递归闭环已经形成，但审计机制几乎空白。

2、HTTP/2 Bomb：Codex 把十年老漏洞焊成新武器 confirmed

安全研究员 Quang Luong 披露「HTTP/2 Bomb」：OpenAI Codex 把 2016 年已公开的 HPACK 压缩炸弹与 Slowloris 串联，攻击 nginx、Apache、IIS、Envoy 默认配置。单台家用 100Mbps 机器可在数秒内打瘫服务器；对 Apache，一个客户端约 20 秒占满 32GB 内存。约 88 万 HTTP/2 站点可能受影响。

3、Anthropic 一年 AI 网络威胁图谱：MITRE ATT&CK 已不够用 confirmed

Anthropic 分析 832 个因恶意网络活动被封禁的账号，发现攻击者正将 AI 用于入侵后阶段（横向移动、权限提升），使低技能攻击者也能执行高复杂度操作。MITRE ATT&CK 尚未覆盖 Agent 链式编排等新型行为。

4、Coinbase Mux：多 Agent 编排工具让重度用户 PR 合并量翻 3.5 倍 confirmed

Coinbase 工程师从执行者演变为 Agent 舰队编排者，内部多 Agent 工具 Mux 从个人 side project 增长至 600+ 用户。重度用户合并 PR 数量达基线 3.5 倍。这是交易所级别组织中 AI 工程化落地的罕见量化案例。

5、MAI-Thinking-1：微软发布 7 款 MAI 模型，旗舰零蒸馏零合成数据 confirmed

Microsoft Build 发布 7 款 MAI 模型，旗舰 MAI-Thinking-1 以 109 页技术报告披露零蒸馏、零合成数据训练路径，在 AIME 2025 达 97%、SWE-Bench Pro 达 53%。同时推出 Frontier Tuning 企业定制方案——微软终于在模型层面有了自己的旗舰。

🧩 本期概念库

1. 认知债务 (Cognitive Debt)

一句话解释：团队失去对系统的共同理解——不只是代码难维护，而是没人知道系统「为什么」是这样的。AI 加速生成代码会放大这种债务。
背景来源：ACM Queue - Margaret-Anne Storey
为什么重要：AI 编码工具让每个人产出更多代码，但团队对代码库的集体理解在同步稀释。
团队应用场景：定期做「代码叙事会议」——不是 code review，而是让成员讲述「这个模块为什么这样设计」。如果没人能讲清楚，那就是认知债务。

2. Skill 供应链信任 (Agent Skill Supply Chain Trust)

一句话解释：Agent Skill 的分发体系缺乏有效的恶意检测机制——现有扫描器可在一小时内被绕过，信任模型从根本上已破裂。
背景来源：Trail of Bits - The Sorry State of Skill Distribution
为什么重要：当 Agent 生态从「少数精选工具」扩展到「万级第三方 Skill」，供应链安全风险指数级增长。
团队应用场景：对 Agent Skill 采用与 npm 包同等级的审计策略：版本锁定、来源验证、最小权限。不要信任任何自动扫描的绿标。

3. 递归自我改进反馈环 (Recursive Self-Improvement Loop)

一句话解释：AI 系统加速 AI 系统自身开发的正反馈循环。Anthropic 数据显示任务完成能力约每四个月翻倍，80% 代码由 AI 编写。
背景来源：Anthropic Institute - Recursive Self-Improvement
为什么重要：当循环速度超过人类审计能力时，传统的「人在回路中」治理模式失效。
团队应用场景：在 AI 辅助开发流程中建立硬性「人类审查节点」——不是所有步骤都需要人看，但关键决策点必须有独立于 AI 的验证。

4. TITO 不变量 (Token-In Token-Out Invariant)

一句话解释：多轮 Agent RL 训练中，永远不对已解码的 token 重新编码。违反这一不变量会导致梯度作用于模型未采样的序列，引入隐性训练错误。
背景来源：Hugging Face - Agentic RL
为什么重要：随着 Agent 多轮训练成为标准实践，这个看似细节的不变量决定了训练结果的正确性。
团队应用场景：在构建多轮 Agent 训练管线时，将 TITO 不变量加入 CI 检查。

5. IDD 重要决策文档 (Important Decisions Document)

一句话解释：为每个长期项目维护一份记录关键决策及其被拒绝备选方案的文档。加速新人上手、避免重复争论、提升问责效率。
背景来源：ACM Queue - Thomas Limoncelli
为什么重要：AI 加速开发后，决策密度提升但记录密度下降——IDD 是对抗认知债务的实操工具。
团队应用场景：为团队核心项目建立 IDD：每个重大技术决策记录「选了什么」「为什么」「拒绝了什么」。
