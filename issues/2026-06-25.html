第 47 期：AI 的瓶颈从模型能力，转向推理工厂

第 47 期 · 2026年6月25日，星期四

✨ 本期亮点：OpenAI/Broadcom 发布 Jalapeño 推理芯片 · Qualcomm 收购 Modular 强化跨硬件 AI 软件栈 · Cloudflare 开放 self-managed OAuth · GitHub 推出企业级 break-glass 凭证吊销 · Gemini Computer Use 进入 3.5 Flash 公测 · Krea 2 开放 12B 图像模型权重 · Datadog 用 Claude/Cursor 迁移实时路由系统 · 企业开始从 tokenmaxxing 转向 token rationing

NVIDIA 45°C 液冷官方图：当推理规模进入 gigawatt 级，芯片、冷却、网络和调度都成为 AI 产品体验的一部分。
🎯 本期核心判断：AI 竞争正在从“谁的模型更强”进入“谁能把推理成本、芯片、网络、冷却、权限和预算控制成可运营系统”的阶段；下一轮护城河会长在推理工厂和控制面里。
⏱ 本期建议阅读顺序
先看主故事：Jalapeño 为什么意味着模型公司开始下沉到芯片、网络和调度层。
再看三条冲突趋势：推理工厂、授权控制面、AI 辅助生产迁移。
最后看工具和文章：RubyLLM、Nub、Vercel、Krea 2、Greptile 与企业 AI 预算。

🔥 主故事

Jalapeño：OpenAI 开始把模型公司做成推理工厂

过去模型公司最重要的问题是“模型能不能更聪明”；现在 OpenAI 把问题改写成：“每一次推理能不能更便宜、更稳定、更低延迟地送到用户面前？”

OpenAI 与 Broadcom 在 6 月 24 日发布 Jalapeño，称其为 OpenAI 第一颗 Intelligence Processor，也是双方多代计算平台的第一颗 AI 加速器。官方信息显示，这颗芯片从设计到 tape-out 用了 9 个月，由 OpenAI 模型加速部分设计流程，工程样片已经在实验室按生产目标频率和功耗运行 ML 工作负载，包括 GPT-5.3-Codex-Spark。Broadcom 和 Celestica 参与芯片实现、板卡、机架系统集成、高性能网络和规模化生产。

核心冲突前沿 AI 的核心矛盾正在从模型能力不足，转向推理成本、功耗、延迟、供应链和数据中心容量不足。模型越像实时服务，硬件和控制面就越像产品边界。
转折点OpenAI 不只是采购 GPU，而是把芯片架构、kernel、内存移动、网络、调度、部署系统和产品体验放进同一个优化循环；更好的模型也被用来加速下一代硬件设计。
为什么现在发生ChatGPT、Codex、API 和未来 Agent 产品把推理变成高频生产负载。企业端同一天也在讨论 token 预算、授权 OAuth、凭证吊销和成本可观测性，说明“算得起、管得住、审得清”已经变成 AI 落地的硬约束。
对团队的启发团队做 AI 产品时，不能只把模型当 SaaS 接口看。需要从第一天记录 token 成本、延迟 SLO、模型路由、凭证边界、预算阈值和降级策略，否则规模一上来，产品体验会被基础设施账单和控制面风险反向定义。

我的判断：Jalapeño 的意义不只是 OpenAI 有了一颗芯片，而是模型公司开始拥有“从产品需求到硬件约束”的完整反馈回路。未来 AI 应用的差距会越来越少来自 prompt 技巧，越来越多来自单位推理成本、尾延迟、可用容量和权限控制。

AI 的下一个护城河，不是多会回答，而是能不能把每一次回答便宜、稳定、低延迟地送到用户面前。

来源：openai.com

⚡ 冲突趋势

模型能力 vs 推理工厂

模型越来越强，但真正限制规模的开始是电力、冷却、网络、芯片供应和单位 token 成本。

Jalapeño、NVIDIA 45°C 液冷和 Qualcomm/Modular 都说明：AI 的竞争正在从模型层沉到工厂层。

openai.com · blogs.nvidia.com · investor.qualcomm.com

API token 时代 vs 授权控制面

Agent 和集成越多，长期 API token 越像不可治理的影子权限。

Cloudflare OAuth、GitHub break-glass 吊销和 Vercel OIDC audience 都在把“谁能代表谁做事”变成平台基础能力。

blog.cloudflare.com · github.blog · vercel.com

AI 写代码 vs AI 进生产迁移

AI 能快速生成代码，但生产系统需要测试、蓝绿验证、性能优化和人类架构判断。

Datadog 的经验不是“把迁移交给 AI”，而是把 AI 放进窄上下文、强测试、真人决策的迁移流水线。

datadoghq.com · greptile.com

📰 科技动态

1、Qualcomm 宣布收购 Modular：AI 软件栈成为数据中心战略核心 confirmed

Qualcomm 宣布已达成收购 Modular 的协议，目标是强化从设备、边缘到数据中心的生成式与 Agentic AI 软件基础。官方强调 Modular 的平台能在 CPU、GPU、NPU 和 custom ASIC 上运行模型，减少为不同加速器重写代码。交易预计在 2026 年下半年完成。

2、Cloudflare 开放 self-managed OAuth：Agentic 工具不再只靠 API token confirmed

Cloudflare 宣布 self-managed OAuth 面向所有客户开放，让开发者能创建 OAuth 应用，用户通过标准授权流授予 scoped access。Cloudflare 还披露了 Hydra 迁移后的性能数据：API P95 从 185ms 降到 101ms，Go heap allocation 降 40%，CPU 从 1.07 cores 降到 0.67 cores。

3、GitHub 企业级 break-glass：一次性吊销用户全部凭证 confirmed

GitHub Enterprise owners 现在可以在安全事件中对某个用户或全体用户执行批量凭证操作，包括撤销 SSO authorization、删除 token 和 SSH key、通过 org-level REST API 做组织级撤销，并通过 audit logs 和邮件通知追踪结果。

4、NVIDIA 45°C 液冷：AI factory 的冷却也变成战略变量 confirmed

NVIDIA 介绍 Rubin 代 AI 基础设施的 45°C 液冷设计：100% 液冷、闭环系统、无风扇；在有利气候下可通过 dry cooler 免 chiller 运转，把传统冷却塔系统每 MW 每年约 260 万加仑的设施冷却用水降到接近 0。

5、Datadog：用 Claude/Cursor 迁移实时路由系统，但测试和蓝绿验证说了算 confirmed

Datadog 复盘 Stream Router 存储迁移：从 FoundationDB KV 模型迁到 PostgreSQL + DuckDB，用 Claude 和 Cursor 做方法级重构，但架构设计、SQL 性能优化和生产验证仍由工程师掌控。迁移后，部分 45 分钟操作降到约 1 秒，数据集缩小 40 倍，数据库成本下降 90%。

🤖 AI 相关

1、Gemini API：Computer Use 进入 Gemini 3.5 Flash 公测 confirmed

Google 在 Gemini API release notes 中宣布，Computer Use tool 已在 Gemini 3.5 Flash 上进入 public preview，包含带 intent 的简化动作、浏览器/移动端/桌面环境支持、可配置安全策略和 prompt injection detection。

2、Krea 2 技术报告：开放 12B 图像模型权重，主打审美多样性与控制 announced

Krea 发布 Krea 2 技术报告，介绍面向 creative exploration 的图像基础模型，覆盖数据治理、架构、多阶段训练和分布式基础设施。模型权重和推理以 permissive license 发布，目标是摆脱单一默认审美，让创作者在更大风格空间里搜索。

3、Hugging Face + NVIDIA：NeMo AutoModel 把 MoE 微调做成同 API 加速路径 confirmed

Hugging Face 与 NVIDIA 介绍 NeMo AutoModel：在保持 Transformers v5 类似 from_pretrained() 接口的同时，加入 Expert Parallelism、DeepEP fused all-to-all dispatch 和 TransformerEngine kernels。官方测试显示，在 Qwen3-30B-A3B 和 Nemotron 3 Nano 30B-A3B 上训练吞吐提升 3.4-3.7 倍，GPU 内存降低 29-32%。

4、Netflix 研究可控 AI 视频编辑：从生成视频转向“可编辑现实” announced

Netflix TechBlog 发布早期研究探索，关注更可控的 AI 视频编辑，让创作者在既有视频上做更细粒度、可约束的修改，而不是只依赖文本生成整段视频。

5、企业从 tokenmaxxing 转向 token rationing：AI 成本进入 CFO 视野 reported

TechCrunch 报道企业开始限制员工把 AI 用在 PDF 转 PPT 等基础任务上，并引用 404 Media 关于 Accenture 内部 token reserve 管理的报道。文章把这一阶段称为从 tokenmaxxing 进入 token rationing：AI 预算不可预测，CFO/COO/CIO 开始追问价值和可见性。

🧩 本期概念库

1. Intelligence Processor

一句话解释：OpenAI 对 Jalapeño 的称呼，强调它不是通用加速器，而是围绕 LLM inference 的芯片、网络和服务模式做全栈优化。
背景来源：OpenAI/Broadcom Jalapeño announcement
为什么重要：它把模型服务的成本、延迟和硬件利用率直接变成产品竞争力。
团队应用场景：在 AI 产品评审中加入单位推理成本、尾延迟、模型路由和容量预案。

2. Performance per watt

一句话解释：单位功耗下能完成多少有效计算或推理，是 AI 数据中心最核心的经济指标之一。
背景来源：OpenAI/Broadcom、Qualcomm、NVIDIA 同日信号
为什么重要：当电力和冷却成为瓶颈，性能绝对值不如“每瓦产出”能决定可规模化程度。
团队应用场景：做模型选型时不只比较质量，还要比较成本、吞吐、延迟和能否被调度系统稳定利用。

3. Blue/green validation

一句话解释：把新旧系统并行运行，用真实生产请求持续比对输出，再逐步切流。
背景来源：Datadog Stream Router migration
为什么重要：AI 辅助迁移可以提高实现速度，但最终信任来自可重复测试和线上对照验证。
团队应用场景：关键系统改造时先设计验证闭环，再决定能让 AI 承担哪些窄任务。

4. Token rationing

一句话解释：企业从鼓励无限使用 AI，转向给任务、团队或员工设置 token 预算、阈值和成本可见性。
背景来源：TechCrunch enterprise AI budget reporting
为什么重要：AI 成本开始从创新预算进入 CFO、COO、CIO 的管理视野。
团队应用场景：为内部 AI 工具增加 per-task cost、预算告警、模型降级和缓存策略。

5. Delegated access control plane

一句话解释：用 OAuth、OIDC、短期凭证、audience 和 revocation 统一管理应用、Agent 和人员之间的代表关系。
背景来源：Cloudflare OAuth、GitHub credential revocation、Vercel OIDC
为什么重要：Agent 越多，权限越不能靠长期 token 和口头流程管理。
团队应用场景：把 Agent 权限视为生产身份，纳入授权、审计、吊销和最小权限策略。
