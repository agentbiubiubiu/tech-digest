第 107 期：Agent 开始进入 Android Studio 的工程现场

当外部 Agent 不再只看聊天框，而能进入 Android Studio 的项目、工具与设备上下文，竞争点就从“会不会生成代码”转向“能否完成并证明交付”。

今天值得理解的是 Agent 正在从独立聊天工具变成研发环境里的可插拔执行者；采用与否应由上下文质量、权限边界、验证证据和返工成本决定，而不是模型名单。

主故事

Android Studio 把 Agent 选择权交给开发者，但验收责任没有外包

Google 在 Android Studio Rabbit 2 Canary 中预览 BYOA，首批列出 Claude Agent、Codex 与 Antigravity。

外部 Agent 能获得更贴近 Android 工程的基础设施，但预览渠道、账号套餐与多家提供商行为差异会把新的不确定性带进 IDE。

真正新增的不是聊天入口，而是“Agent 可替换、工程上下文与工具层留在 IDE”这一接口边界。

我的判断：对 YG 最有价值的是把同一小任务交给现有链路和 BYOA 做端到端对照；没有构建、设备、日志和返工证据，就不把接入视为提效。

三个冲突趋势

可插拔 Agent vs 可预测交付

选择权增加，但账号、预览渠道和行为差异也增加。

先固定验收协议，再比较 Agent。

更长自主循环 vs 明确停止条件

模糊测试能自动扩覆盖率，但算力消耗不会自动收敛。

GitHub 的平台期阈值把“何时停”写进系统。

功能速度 vs 可靠发布

Beta 功能已进入计划，PostgreSQL 仍选择撤回。

删除证据不足的能力，也是工程速度。

概念库

BYOA

Bring Your Own Agent：IDE 提供工程与工具上下文，开发者选择外部 Agent。

平台期停止条件

连续若干轮收益低于阈值就停止，避免 Agent 为最后一点覆盖率持续烧算力。

Proof of Presence

高影响动作前要求一次新鲜的人类认证，而不是只信长期会话或 Token。

投机解码

小模型先批量猜候选 Token，再由目标模型验证，用额外参数换取速度。

团队行动

  • Agent 接入先固定验收表：统一记录构建/测试、设备结果、总耗时、返工和失败恢复。
  • 给长循环明确停止预算：覆盖、性能或修复循环都定义平台期阈值与最大轮次。
  • 高影响动作必须重新确认：Token、Webhook、发布与安全设置变更前要求显式授权并回读。

3–5 分钟播客稿

今天最值得注意的不是又多了一个会写代码的模型，而是 Android Studio 开始让外部 Agent 直接进入它的工程现场。问题随之改变：谁能写代码已经不稀缺，真正稀缺的是谁能拿到正确上下文、调用正确工具，并留下可验收的结果。

主故事

Google 在 Android Studio Rabbit 2 Canary 中预览 Bring Your Own Agent，也就是 BYOA。文档列出的首批选择包括 Claude Agent、Codex 和 Google Antigravity，并允许消费级或企业级方案接入，但仍受各家提供商账号与套餐约束。关键新增不是一个聊天入口，而是让外部 Agent 借用 Android Studio 为 Android 研发准备的项目上下文和工具基础设施。对我们而言，这可能缩短从理解工程到构建、检查和设备验证的距离；但它目前仍是 Canary 预览，不能替代现有稳定链路。最小验证应只选一个可回滚小任务，比较改动正确率、构建证据、日志可读性和人工返工，任何一项退步都不应迁移。

快讯一

GitHub Security Lab 展示了一个 AI 驱动的模糊测试工作流。它会让 Agent 生成或改进 harness，并用覆盖率平台期作为停止条件：连续两轮增量都低于默认百分之一就停止。最有价值的不是让模型无限跑，而是把停止规则、覆盖证据和人工崩溃分诊写进循环。

快讯二

OpenAI 的 Agents API 文档把多 Agent 并发、流式事件和会话生命周期做成托管接口。它适合需要独立子任务和统一回读的服务端流程，但今天还不该因为示例顺畅就重写已有自动化；先验证错误传播、权限、成本和中断恢复。

快讯三

PostgreSQL 19 Beta 4 主动撤回了几项原计划功能，理由是可靠性和可预测发布节奏。这是今天很好的反例：成熟工程并不把功能数量当成功标准，按时删掉证据不足的功能也是交付能力。

团队行动

今天最值得采取的动作只有一个：如果 Android 团队已经能使用 Rabbit 2 Canary 和对应 Agent 账号，挑一个不涉及生产数据的小修做对照实验；否则先不安装，只把验收表准备好。验收至少记录任务完成、构建或测试证据、设备结果、总耗时、人工返工和失败恢复。

边界

其余工具保持克制。Claude Code 的本次更新修复了磁盘配额被模糊成退出码一、网关历史导致四百错误等真实故障；ClickHouse、Datasette 和视觉模型优化各有价值，但都需要目标项目或硬件条件。没有明确场景时，知道它们存在比立刻引入更划算。

这期的共同线索是：Agent 正在进入 IDE、测试和服务端编排，但真正可迁移的不是产品名字，而是上下文、停止条件、权限和回读证据。先用一个小任务证明闭环，再决定是否扩大。
