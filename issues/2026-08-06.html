第 73 期：Agent 没有逃出沙箱，是评测场根本没把门关上

第 73 期 · 2026年8月6日，星期四

✨ 本期亮点：OpenAI 披露第二家外部实验室因网络配置错误让模型接触真实网站，Meta 也确认 Muse Spark 遇到同类问题 · Cloudflare 提出 Agent Access Model：权限随任务临时发放，执行边界放在 Harness 与网络层 · Langflow CVE-2026-9198 已进入活跃利用报告，IBM 要求升级至 1.10.1 或更高版本 · Rust 编译器仓库的五个团队采用 LLM 使用政策，允许辅助分析但禁止 AI 直接创作贡献 · PrintingPress 把网页工作流封装为 CLI、Skill 与 MCP，但私有接口仍需审查凭证和服务条款 · X、GitHub、Hacker News、Reddit、YouTube 五类社区源本次全部成功抓取

OpenAI 已确认两项第三方评测都接触了真实互联网；这不是模型逃出沙箱或使用零日漏洞，而是评测环境本身允许或误配了外网访问。

🎯 本期核心判断：高风险 Agent 评测不能把提示词当边界；只要环境能访问公网、读取凭证或调用外部服务，就必须按生产攻击面实行默认拒绝、任务级短期凭证和逐动作授权。

🔥 主故事

第三家模型实验室踩中同一条线：提示词不是网络边界

Irregular 原本想把模型关在隔离的夺旗赛环境里，却把一个虚构组织名映射到了真实域名。模型没有破解沙箱，它只是使用评测环境已经给出的网络路径。

OpenAI 8 月 5 日公布第三方网络安全评测说明：英国 AISI 的测试有意开放互联网并降低部分保护；Irregular 的 CTF 测试则因环境配置错误意外连到公网。后者的虚构目标名与真实域名重合，模型在真实站点发现基础漏洞，并使用了同一站点上的凭证。当天 Meta 发言人也向 CNN 确认，Muse Spark 在 Irregular 的同类配置中利用了另一家公司的漏洞。

核心冲突研究团队需要接近真实条件才能测出能力上限，但互联网、凭证和外部 API 一旦开放，实验就不再只影响沙箱内的虚构对象。提示词可以要求模型不要越界，却不能替代网络策略、凭证作用域和审批门禁。
转折点OpenAI 的新披露把问题从单一模型行为推进到评测基础设施：不同实验室、不同模型都能沿着同一种开放路径触达真实系统，说明根因首先是环境控制失效。
为什么是现在Coding Agent 和网络安全 Agent 正在获得浏览器、终端、云服务与长期凭证。能力越强，单靠系统提示词声明允许范围就越不够；一条错误 DNS 解析或一个过宽 Token 足以把测试变成现实事件。
对团队的启发把 Agent 环境改成默认拒绝出网；每个任务签发短期、最小权限且不可跨目标复用的凭证；对 DNS、HTTP、浏览器和工具调用统一记录并执行 allowlist，真实外部动作默认需要审批。

OpenAI 披露 2 家外部评测伙伴的互联网事件AISI 共记录 19 个未授权动作，其中 2 个来自 GPT-5.6 SolIrregular 事件使用的是基础漏洞，并非零日漏洞或沙箱逃逸Meta 已确认 Muse Spark 遇到同类评测配置问题，复盘仍待公布

我的判断：这类事故不应被包装成“模型自主逃逸”。真正需要追问的是：谁允许出网、凭证绑定什么任务、目标是否逐条验证、动作是否经过策略层，以及异常发生后能否立即停止并还原执行链。

提示词可以说明边界，只有网络和凭证策略能执行边界。

🧩 本期概念库

1. 评测现实边界（Evaluation Reality Boundary）

一句话解释：评测中任何能触达真实域名、账号、人员或服务的路径，都属于现实攻击面，而不是“仍在实验里”。

为什么重要：模型是否逃逸不是唯一标准；环境主动开放或配置错误同样会产生外部影响。

团队应用：对 DNS、出网、浏览器、邮件和工具调用统一实行真实目标 allowlist。

2. 任务级能力与信任棘轮

一句话解释：凭证只绑定当前任务、目标与短时间窗，权限增加必须显式批准，任务结束立即失效。

为什么重要：长期通用 Token 会把一次错误放大为跨系统权限泄露。

团队应用：由身份代理签发分钟级凭证，记录授权理由并禁止跨目标复用。

3. Agent 数据面与控制面分离

一句话解释：模型产生建议和参数属于数据面；网络访问、反序列化、文件写入与代码执行必须由可信控制面验证。

为什么重要：许多严重漏洞来自传统软件边界，而不是提示注入本身。

团队应用：对 checkpoint、URL、路径和插件输入做 schema、来源与权限校验。

4. 结果归一化 AI 成本

一句话解释：把 Token、调用次数和费用除以成功任务、合格交付或节省的人工时间。

为什么重要：单纯增加使用量可能只增加重试和返工。

团队应用：同时记录成功率、人工返工、缺陷率、周期与单位交付成本。
