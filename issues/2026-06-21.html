第 43 期：Agent 开始要自己的身份、额度和上线通道

第 43 期 · 2026年6月21日，星期日

✨ 本期亮点：GitHub 因 AI 代码量暴涨补多云容量 · Estonia 推进 AI Agent 数字身份 · Cloudflare 给 Agent 临时部署账号 · GitHub AI credits 进入用量指标 · Vercel eve 把 Agent 做成目录化运行时 · Modal speculative decoding 超过 1000 tok/s · AGENTS.md 配置气味成为新工程债 · Linux 6 年清掉 strncpy · Headroom 主打 60-95% token 压缩

Cloudflare Temporary Accounts 把无头 Agent 的部署入口从人工注册改成临时、可认领、可过期的账号流程。
🎯 本期核心判断：Agent 的下一阶段竞争不再只是模型能力，而是谁能给非人类操作者提供可审计的身份、容量、权限、成本和上线通道。

🔥 主故事

GitHub 的 AI 流量把 Microsoft 推向 AWS：Agent 时代先撞上的不是智力，而是容量

你以为 AI 编程的瓶颈是模型写错代码，结果第一个被顶到墙上的可能是 GitHub 自己。

DevOps.com 援引 Business Insider 报道称，Microsoft 已开始为 GitHub 增补 AWS 计算容量，以应对 AI 辅助开发带来的需求暴涨。Microsoft 没有直接确认 AWS，但确认 GitHub 正采用多云方式支撑增长。

核心冲突Microsoft 想把 GitHub 长期迁到 Azure，但 AI 编码把代码提交、构建、评审和 Agent 操作一起放大，可靠性压力快过了云迁移叙事。
转折点过去平台容量按人类开发节奏规划；现在 Agent 能并发开 PR、跑 CI、触发审查、消耗 token 和 Actions minutes，负载曲线不再像人类团队。
为什么现在发生Copilot、Cursor、Claude Code、Codex 等工具把“写代码”从单点补全扩展到长任务工作流，平台要承受的不只是文本生成，而是完整软件交付链路的流量。
对团队的启发我们自己的 AI 工程链路也不能只看模型效果：要把 Agent 触发的 CI、代码审查、预算、权限、沙箱和发布动作全部纳入配额和可观测性。

2025 年约 10 亿次 commit2026 年可能超过 140 亿次 commitAzure 迁移目标 2027 年完成

我的判断：我的判断是，Agent 时代最先商业化的控制面不会是更漂亮的聊天界面，而是容量、身份、账单、权限、审计和回滚。谁能把这些基础设施变成默认能力，谁就会真正吃到 Agent 生产力的复利。

当代码量从人类速度变成 Agent 速度，平台的第一性能力就从“会不会写”变成“扛不扛得住”。

来源：devops.com

Estonia 的 AI ID codes 和 Cloudflare 临时账号说明，Agent 已经从工具变成需要身份边界的操作者。

AI 让代码产出变快，但 GitHub、CI、评审、用量计费和云容量都要为这个速度买单。

开发效率的收益如果没有配额和可观测性，最后会以平台可靠性和账单波动的形式回来。

📰 科技动态

1、Estonia 准备给 AI Agent 发数字身份：权限、代理关系和责任要写进 ID confirmed

最反常识的点是：Agent 还不是法人，但已经需要“身份证”。Estonia 政府表示将推进 AI ID codes，让 Agent 能在明确限制内代表个人、公司或机构行动，并保留可验证、可审计的授权边界；这对企业 Agent 同样是提醒，不能再让一个 API token 代表所有权限。

2、GitHub Copilot 用量指标开始按用户展示 AI credits：Token 账单进入管理台 confirmed

Copilot usage metrics API 新增每个用户每天消耗的 AI credits，口径来自 usage-based billing API。它看似只是报表字段，实际是在把 AI 编码从“工具满意度”推进到“团队成本治理”：以后谁的 Agent 长任务在烧钱，管理台会看得更清楚。

3、Linux 7.2 删除 strncpy：一个 API 的技术债花了 6 年、362 个提交才还完 reported

这个故事不像新功能，却很适合提醒团队：错误抽象会活得比项目经理还久。Linux 内核终于移除 strncpy，原因包括 NUL 终止语义反直觉、性能冗余填零和长期 bug 风险；六年清理说明“弃用”不是公告，而是持续工程。

4、SMPTE 开放全部标准目录：媒体技术把互操作性从付费墙里拿出来 confirmed

SMPTE 宣布所有已发布标准、推荐实践、工程指南、RDD 以及未来版本都将免费开放。对 AI authenticity、content provenance、IP 化媒体工作流来说，标准可访问性不是公益姿态，而是让实现者少靠二手资料、少踩互操作坑。

5、Cloudflare 复盘 SOCKMAP：理论上零 syscall、零复制，实测却最慢 confirmed

这是一篇值得工程师收藏的负结果文章：SOCKMAP 理论上减少 syscall、用户态唤醒和复制成本，但 Cloudflare 在 25Gbps 裸金属测试里发现它反而最慢，还暴露了最高 64ms 延迟异常。它的价值不在结论漂亮，而在告诉团队要公开验证“不该输”的方案。

🤖 AI 相关

1、Cloudflare Temporary Accounts：Agent 可以先部署，60 分钟后由人认领 confirmed

Cloudflare 允许 Agent 用 `wrangler deploy --temporary` 直接部署 Worker，不必先注册、点 OAuth、复制 API token 或过 MFA。临时账号 60 分钟后可认领或自动过期，这本质上是在给后台 Agent 设计“临时身份 + 临时环境 + 可验证产物”的上线循环。

2、Vercel eve：把 Agent 组织成目录，把审批、沙箱、eval 变成默认运行时 confirmed

eve 把一个 Agent 描述成目录：instructions、tools、skills、subagents、channels、schedules 都在文件系统里。真正值得注意的是它把 durable execution、sandboxed compute、human-in-the-loop approvals、subagents 和 evals 放进默认框架，说明 Agent 开发正在复制 Web 框架的约定式路径。

3、Modal：Speculative decoding 从小优化变成推理系统主战场 confirmed

Modal 发布多组 DFlash speculator，称新 draft models 在多种工作负载上额外带来 5-20% 加速，并让 Qwen 3.5 122B-A10B 在 B200 上超过 1000 tok/s。这里的信号是：推理优化不只靠 kernel 工程，越来越像一个可以随业务数据继续训练的小模型问题。

4、AGENTS.md 也有 code smell：100 个热门仓库里，Lint Leakage 最常见 reported

一篇 arXiv 论文把 Agent 配置文件的问题命名为 configuration smells，并在 100 个开源项目的 AGENTS.md/CLAUDE.md 中识别出 207 个实例。最常见的是 Lint Leakage：把 linter 已经能检查的规则塞进上下文，白白浪费 token，还稀释真正重要的架构约束。

5、OpenAI Codex App 增加 Record & Replay：把演示过的工作流变成可复用 skill confirmed

Codex app 26.616 增加 Record & Replay，可把 macOS 上演示过的工作流变成 reusable skill，同时增加自动化运行历史批量操作和本地/远程线程 handoff。它说明 Agent 产品正在从“会做一次”走向“把一次操作沉淀成团队能力”。

📝 文章推荐

1、CI/CD with Robert Erez：Agent 不怕等，流水线就该更会验证

这期 Pragmatic Engineer 访谈适合团队周会讨论：AI 时代不是要把 CI/CD 砍到最短，而是要把慢验证、渐进式发布、特性开关和回滚策略重新算账。人类开发者怕等，Agent 可以等；生产事故不会因为代码由 AI 写就更便宜。

2、PostgresBench：ClickHouse 把 OLAP 的可复现 benchmark 文化搬到 Postgres

PostgresBench 用 pgbench、256 clients、16 threads、10 分钟运行、100GB/500GB 两种规模，公开比较 managed Postgres 服务。真正值得学的是方法论：当性能成为销售主张，配置、脚本、原始结果和争议入口都要公开。

3、Frontier post-training recipe review：2026 的后训练配方开始从单体 RL 转向多教师蒸馏

Interconnects 把 DeepSeek R1、MiMo Flash v2、Nemotron 3 Ultra、MAI-Thinking-1 等配方串起来看，提出 2026 风格正在向 MOPD 靠拢：先训练多个领域教师，再把学生自己的轨迹路由给专家蒸馏。对团队的启发是，模型能力提升越来越像组织知识整合。

4、Why AI token prices are about to plummet：Blackwell 把 token 经济学推向下一轮重定价

Business Insider Africa 援引 SemiAnalysis 对 Blackwell 与 Hopper 的比较：GB300 NVL72 级系统在每百万 token 成本上可能从 4.20 美元降到 0.12 美元。即便要谨慎看待模型和负载差异，这个方向也说明 token 价格战不是营销，而是硬件代际变化的经济结果。

🧩 本期概念库

1. Non-human Identity

一句话解释：为 Agent、自动化工作流或服务代理分配可验证、可限制、可审计的身份，而不是借用人的全量凭证。
背景来源：Estonia AI ID codes 与 Cloudflare Temporary Accounts
为什么重要：Agent 进入真实系统后，身份边界决定责任归属和权限半径。
团队应用场景：内部 Agent 不应共享个人 token；应有独立身份、过期时间、作用域、审计日志和额度。

2. Agent Control Plane

一句话解释：把 Agent 的权限、成本、队列、沙箱、审批、回滚和可观测性作为统一控制面管理。
背景来源：GitHub 容量压力、GitHub AI credits API、Vercel eve、Modal Sandboxes
为什么重要：模型能力越强，控制面越像产品本体。
团队应用场景：上线任何长任务 Agent 前，先定义预算、并发、可访问资源、人工确认点和失败处置。

3. Configuration Smell

一句话解释：AGENTS.md/CLAUDE.md 中会降低 Agent 效果的坏味道，例如上下文膨胀、Lint Leakage、技能泄漏和冲突指令。
背景来源：Configuration Smells in AGENTS.md Files
为什么重要：Agent 指令文件会常驻上下文，坏指令会持续消耗 token 并误导执行。
团队应用场景：把通用风格规则交给 linter，把专项知识放 skill，AGENTS.md 只保留高价值、稳定、项目特定约束。

4. Reproducible Benchmark as Product Contract

一句话解释：把 benchmark 从宣传图变成可运行脚本、公开配置、原始数据和可提交争议的协议。
背景来源：ClickHouse PostgresBench 与 Cloudflare SOCKMAP 负结果
为什么重要：AI 和基础设施产品都越来越依赖性能叙事，可复现性会影响信任。
团队应用场景：内部性能评测要保留脚本、数据、环境、重复次数和异常处理规则，避免“截图驱动决策”。

5. MOPD

一句话解释：Multi-teacher On-Policy Distillation：让学生模型采样自己的轨迹，再由多个领域教师提供蒸馏信号，把专家能力合并进一个模型。
背景来源：Interconnects frontier post-training recipe review
为什么重要：后训练正在从单体 RL 转向多专家整合，类似组织知识管理。
团队应用场景：做内部 Agent 时可以借鉴这个思路：用多个专家评审器/规则器合并反馈，而不是依赖单一 Judge。

GitHub 容量压力

代码从人类速度变成 Agent 速度，平台要先扛住。

对内部平台来说，Agent 触发的 commit、CI、review 和 deploy 都应纳入配额。

Agent 身份与临时账号

Agent 需要的不是万能 token，而是有限、可过期、可认领的身份。

内部 Agent 的凭证要有作用域、过期时间、审计和责任归属。

Agent 运行时变成产品

Demo 会调用工具不难，难的是崩了还能继续、危险动作会暂停、网络访问能限制。

不要只采购模型能力，要建设 Agent 控制面。

今天的核心判断：Agent 时代的护城河正在从模型能力转向控制面能力。能把身份、容量、账单、沙箱、审批和可观测性做扎实的团队，才会真正把 AI 提效变成可持续生产力。
