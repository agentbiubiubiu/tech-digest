🧩 本期概念库

1. Tokenmaxxing（指标异化）

一句话解释：当 Token 消耗量被设为 AI adoption KPI 时，理性行为是刷指标而非改工作流——Goodhart 定律在 AI 时代的具体表现。
背景来源：Amazon 内部 AI 排行榜事件
为什么重要：解释为什么 AI 铺开后反而出现「假 adoption」现象，以及 ROI 审查为何不可避免。
团队应用场景：团队 AI KPI 应绑定 PR 质量、缺陷率、交付周期等可验证产出，禁止用 Token 数或登录天数考核。

2. Video Agents

一句话解释：以视频理解与生成为核心的 Agent 架构——模型不再只处理文本，而是把视频帧序列作为 Agent 的感知输入和动作输出。
背景来源：Latent Space Video Agents 专题
为什么重要：多模态 Agent 的下一个战场是视频流，对监控、交易图表分析、UI 自动化等场景有直接迁移价值。
团队应用场景：关注视频理解 Agent 在 UI 测试、K 线图表解读等金融场景的落地可能。

3. Index-as-Model

一句话解释：把索引结构本身作为可学习的模型组件，而非固定的查表结构——检索与排序的边界被重新定义。
背景来源：Meta SilverTorch 工程博客
为什么重要：RAG 和推荐系统的索引架构正在从工程问题变成 ML 问题。
团队应用场景：评估现有搜索/推荐索引是否有可学习化的空间，尤其在交易对检索和用户偏好排序场景。

4. LLM 评测飞轮

一句话解释：从线上反馈 → 离线 benchmark → prompt/模型迭代 → 再上线的闭环评测体系——公开 benchmark 被污染后的唯一可靠路径。
背景来源：DoorDash LLM 评测系统 + Datadog Bits AI Eval
为什么重要：AI 工具选型不能只看公开榜单，必须建立业务场景的真实评测集。
团队应用场景：为交易相关 AI 功能（客服、风控文案、代码生成）建立内部 golden set 和回归评测流程。
