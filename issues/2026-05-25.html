🔥 头条深读

本周最显著的信号不是某个模型又刷新了基准，而是整个行业的竞争轴心发生了结构性偏移：所有模型实验室都在变成 Agent 实验室。Latent Space 的 Swyx 用一篇 AINews 把这个趋势讲透了——Greg Brockman 公开表态「模型本身不再是产品」，AI21 从 API 转向全栈 Agent 交付，DeepSeek 组建了专门的 harness 团队。

发生了什么：三件事同时发生。Google 宣布将开源的 Gemini CLI 过渡到闭源的 Antigravity CLI，6 月 18 日起免费用户将失去终端 Agent 入口。微软内部撤销了 Claude Code 许可证，统一推 GitHub Copilot CLI。与此同时，LangChain 发布了Agent Harness 架构标准，将沙箱、上下文压缩、长时任务循环等原语系统化。

为什么重要：Agent 基础设施的竞争正在沿三条线展开。第一条是运行时之争：Modal 以 $4.65B 估值拿下 $355M C 轮，累计发出超 10 亿个沙箱；Daytona 实现 74% 月环比增长、日活 85 万沙箱、60ms 冷启动。第二条是工具链锁定：Google 和微软分别通过关闭开源和企业政策把开发者圈进自家 Agent IDE。第三条是协议标准化：LangChain 的 Agent Streaming Protocol 从 token 流升级为结构化事件流，MCP 发布了 2026-07-28 RC 无状态版本。

我的判断：模型能力的差异正在被 harness 工程吃掉。同一个模型在不同 harness 下性价比差 5 倍（参见往期 Open Agent Leaderboard），这意味着谁控制了 Agent 的运行时、评测体系和开发者工具链，谁就控制了 AI 产品的实际体验。Pragmatic Engineer 报道了 Antigravity 2.0 上线后的开发者集体差评——bug 多、UX 差、Gemini token 消耗过快——说明「控制入口」和「做好入口」之间还隔着巨大的工程鸿沟。

对团队的启发：不要把 AI 编码工具当成免费午餐。当平台方开始收拢生态时，团队应该：1）评估自身对单一 Agent 工具链的依赖度；2）关注 MCP/Agent Streaming 等开放协议，降低切换成本；3）在内部建立 Agent harness 评测能力，用真实业务场景而非公开 benchmark 来选型。

🤖 AI 相关

1、Anthropic Glasswing：AI 一月发现万级高危漏洞，安全从发现瓶颈变修复瓶颈 confirmed

Anthropic 公布 Project Glasswing 首月成果：Claude Mythos Preview 与约 50 个合作伙伴共发现超 1 万个高危/严重级别漏洞，同时扫描 1000+ 开源项目又发现数千个。问题不再是「能不能找到漏洞」，而是「修复速度跟不跟得上」。红队评估显示 Mythos 在 V8、Linux 内核、DeFi 合约等目标上的端到端利用能力远超前代模型。

2、NVIDIA Nemotron Diffusion LLM：推理速度提升 2.6 倍 confirmed

NVIDIA 开源 Nemotron-Labs Diffusion（3B/8B/14B），在同一 checkpoint 中支持自回归、扩散和自推测解码三种模式。扩散模式声称每次前向传播生成 token 数为自回归的 2.6 倍，自推测模式达 6 倍，精度与 Qwen3 8B 持平或略优。SGLang 集成中。

3、DeepSeek V4 Pro 永久降价至原价四分之一 confirmed

DeepSeek 宣布 5 月 31 日促销结束后，V4 Pro API 定价将永久定为原始标价的四分之一。促销期间输入缓存命中价格降至 $0.003625/M tokens、输出 $0.87/M tokens，使前沿级模型成本大幅低于竞品。同时推出 Reasonix 原生编码 Agent，强调缓存优化降低长任务成本。

4、Constraint Decay：LLM Agent 随约束累积性能骤降 30 分 confirmed

EURECOM 研究者在 80 个绿地项目和 20 个特性扩展任务上测试了 LLM 编码 Agent（覆盖 8 个 Web 框架 + Clean Architecture + PostgreSQL + ORM）。发现「约束衰减」效应：非功能性需求叠加后，Agent 测试通过率下降约 30 分，45% 的失败由数据层 ORM 缺陷造成。

5、HBM 占 AI 芯片成本 63%，算力建设正在挤压消费电子 confirmed

Epoch AI 分析显示，HBM 内存在 AI 芯片组件成本中的占比从 2024 Q1 的 52% 升至 2025 Q4 的 63%，总组件支出从约 220 亿美元增至约 520 亿美元。HBM 每 GB 消耗的晶圆面积是消费级 RAM 的 3 倍以上，产能挤占正在推高全球智能手机等消费设备的内存成本。

Uber 描述了当 Agent 通过 MCP 跨多个微服务发起多跳调用时，如何保持审计可追溯性。方案包括 Agent Registry、加密委托链和用户上下文跨 Agent 调用传播。这是目前最具体的生产级 Agent 身份认证参考架构之一。

🧩 本期概念库

1. Agent Harness

一句话解释：Agent 运行时中模型之外的全部组件：提示模板、工具、沙箱、编排、中间件、上下文压缩和长任务循环。LangChain 将其定义为一门独立的工程学科。
背景来源：LangChain Blog — The Anatomy of an Agent Harness
为什么重要：同一个模型在不同 harness 下性价比差 5 倍，harness 工程正在成为 AI 产品竞争的核心变量。
团队应用场景：建立团队内部的 harness 评测框架：用真实交易场景（而非公开 benchmark）比较不同 Agent 工具链的成本、延迟和成功率。

2. Agent Streaming Protocol

一句话解释：从 token 级增量流升级为结构化、类型化的 Agent 事件流协议。支持通道（消息/工具/生命周期/自定义）、命名空间（子 Agent/子图身份）、作用域订阅和断线重连。
背景来源：LangChain Blog — From Token Streams to Agent Streams
为什么重要：生产级 Agent UI 需要展示工具调用状态、子 Agent 活动和状态变更，而非只是打字机效果。
团队应用场景：在交易机器人的 Agent 监控界面中，用结构化事件流替代纯文本日志，实现实时工具调用和子任务状态可视化。

3. Constraint Decay

一句话解释：LLM 编码 Agent 在非功能性约束（架构规范、数据库 ORM、类型系统）叠加后性能非线性下降的现象，约 45% 失败来自数据层 ORM 缺陷。
背景来源：EURECOM 研究 — Constraint Decay: The Fragility of LLM Agents in Backend Code Generation
为什么重要：解释了为什么 Agent 擅长原型但在生产后端频繁翻车——约束越多，衰减越严重。
团队应用场景：在 Agent 辅助开发流程中，将架构约束前置为 Agent 可消费的规格文件（CLAUDE.md / cursorrules），并对 ORM 层输出做自动化回归测试。

4. Remediation-Limited Security

一句话解释：AI 使漏洞发现能力呈指数增长后，安全工作的瓶颈从「找不到漏洞」转变为「修不过来漏洞」。Anthropic Glasswing 一个月发现万级高危漏洞即为实例。
背景来源：Anthropic — Project Glasswing: An initial update
为什么重要：重新定义了安全团队的资源分配：投资重心应从扫描工具转向自动化修复流水线和优先级排序系统。
团队应用场景：评估将 AI 安全扫描引入 CI/CD 的时机，同时投资自动化补丁生成和修复优先级排序能力，避免被海量发现淹没。
